Privacy & controls

Where is my data? Chats, notes, and tasks are stored in this browser's local storage on this device. They are not encrypted by this app; anyone with unlocked access to this browser profile may be able to read them.

Network: This app contains no cloud AI API, analytics or chat upload functionality. You need internet only to open/install it for the first time or retrieve app updates. Hosting providers can see site visits, not chat contents sent by this app.

Voice: Spoken replies use your iPhone's speech synthesis if enabled. This app does not request microphone access.

Voice privacy: Spoken replies use device voices. Microphone recognition is optional and may use Apple speech servers. Disable it for strict offline privacy.

Do not put passwords or sensitive company data in this starter app. Offline features are basic: this is not yet a full language model or device controller.
